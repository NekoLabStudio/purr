# Upgrading

Every Purr release gets a page here, with what it needs from your project (and how to do it) and what's new.

To upgrade, download the new release's editor and export templates. Install the templates from the new `.tpz` (Editor > Manage Export Templates > Install from File): each Purr version has its own. Open your project in the new editor and export again.

GDExtensions built against an earlier Purr version need building again against the new one's API.
